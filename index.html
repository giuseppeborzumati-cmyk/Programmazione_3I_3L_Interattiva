Anatomia di una Funzione

Una funzione è un blocco di codice con un nome. Pensa a lei come a un "dipendente specializzato" che fa una cosa sola e la fa bene.

Definizione della Funzione
intTIPO DI RITORNO: La funzione promette di restituire un numero intero. calcolaAreaNOME: Come chiamerai questa funzione nel main. (int basePARAMETRO 1: Variabile locale creata quando la funzione parte., int altezzaPARAMETRO 2: Seconda variabile locale necessaria.)
{
  // 1. Svolgimento del compito
  int area = base * altezza;

  // 2. Restituzione del risultato
  return area;
}

1. Il Tipo di Ritorno (Output)

Dice cosa esce dalla scatola. Se è void, la funzione lavora ma non restituisce numeri o testi al main.

2. I Parametri (Input)

Sono gli ingredienti necessari. Sono variabili LOCALI: nascono quando la funzione inizia e vengono distrutte quando finisce.

3. Return

La parola chiave che ferma la funzione e "lancia" il risultato indietro a chi l'ha chiamata.

Scope: Dove vive una variabile?

Le variabili non sono eterne. Hanno un luogo di nascita e un momento di morte.

int punteggio = 100; // GLOBALE: Visibile ovunque

void gioca() {
  int nemici = 5; // LOCALE: Visibile solo qui
  punteggio++; // OK: vedo la globale
  // vite = 3; // ERRORE: 'vite' è nell'altra stanza!
}

int main() {
  int vite = 3; // LOCALE del main
  punteggio = 0; // OK
  // nemici = 0; // ERRORE: 'nemici' è morta o invisibile
}

Il Passaggio per Valore (Copia)

Quando passi una variabile senza simboli speciali, C++ fa una fotocopia. La funzione colora sulla fotocopia, l'originale resta pulito.

void tentaScambio(int a, int b) {
// 'a' e 'b' sono COPIE nate ora
int temp = a; a = b; b = temp;
// Qui dentro sono scambiati...
} // Qui 'a' e 'b' muoiono!
int main() {
int x = 10, y = 20;
tentaScambio(x, y);
cout << x << " " << y; // Stampa ancora 10 20!
}

Passaggio per Riferimento

Usando & (ampersand) vicino al tipo, dici: "Non copiarmi, dammi l'originale".
La funzione riceve un collegamento diretto alla memoria del main.

void scambioVero(int &a, int &b) {
// a è un ALIAS di x (è la stessa scatola!)
int temp = a;
a = b; // Modifica x originale
b = temp; // Modifica y originale
}
int main() {
int x = 10, y = 20;
scambioVero(x, y);
cout << x << " " << y; // Stampa 20 10!
}
